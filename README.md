# NestUp
NestUp is your personalized move-in planner, budget engine, and smart shopping guide all in one. Whether it's a dorm room or your first home, NestUp has you covered.

To run the platform follow the instructions below:
1. Install npm
2. ``cd nest-up``
3. ``npm install``
4. ``npm run dev``
5. Click on the localhost link and view the website in your browser
